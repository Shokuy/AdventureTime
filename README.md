# Громадное Королевство — Побег из ямы (3D)

Мультяшный 3D-экшен-адвенчер от третьего лица. Маленький Тоша провалился в подземное королевство,
где всё огромное — банки, книги, столы, — а правит им ленивый обжора Король Громадин.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173 — это 3D-версия. Первая 2D-версия осталась по адресу http://localhost:5173/2d.html.
Звук включается после первого нажатия клавиши или клика. Кликни по экрану в игре, чтобы управлять камерой мышью.

Сборка для деплоя (например, на Vercel): `npm run build`, результат лежит в `dist/`.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | бежать (относительно камеры) |
| Мышь | вращать камеру (кликни по экрану, Esc — отпустить) |
| Пробел | прыжок; ещё раз в воздухе — двойной прыжок |
| ЛКМ / J | удар; в воздухе — вертушка с отскоком |
| ПКМ / K | рогатка: щелчок — выстрел с автоприцелом (жёлтая рамка), держи — целишься сам, отпусти (или ЛКМ) — выстрел |
| Shift / L | рывок |
| Q | сменить оружие (меч / вилка-копьё) |
| E | съесть мёд (+3 ♥, с медовыми сотами +5) |
| Колёсико мыши, − / = | отдалить / приблизить камеру (дальность запоминается) |
| Z / [ / ] | повернуть камеру |
| Esc / P | пауза |
| F1 | управление и настройки — в любой момент |

Новые клавиши для игры с друзьями: R — поднять друга / подарить мёд, T — чат, V (держать) — говорить в микрофон,
1–4 — быстрые фразы, G — метка, B — эмоция, Tab (держать) — таблица очков.

**Всё можно переназначить**: Настройки → «Управление» (из главного меню, паузы, лобби, берлоги или по F1). Там же полная
таблица клавиш и кнопок геймпада: выбери ячейку, нажми — и нажми новую клавишу, кнопку мыши или кнопку геймпада
(занятая поменяется местами; ↺ — вернуть как было, внизу — «Сбросить всё управление»). Подсказки в игре показывают
твои клавиши. Там же чувствительность мыши и стика и «Инвертировать по вертикали».

### Настройки

Одно окно с вкладками — из главного меню, паузы (и с друзьями тоже), лобби, берлоги, F1 в уровне:

- **Звук** — общая громкость, музыка, звуки, голоса друзей, «Голос в пространстве», режим микрофона. Шкала «по слуху»:
  20 шагов, первый — еле слышно (≈ −46 дБ), середина ≈ −18 дБ, верх — 0 дБ.
- **Изображение** — полный экран, контуры, мягкие тени, чёткость, тряска экрана, дальность камеры, поле зрения.
- **Управление** — переназначение клавиш и кнопок (см. выше).
- **Сложность** — своя для одиночной игры; в комнате с друзьями видна сложность комнаты (меняет хозяин в лобби).

### Геймпад

DualSense, DualShock 4, Xbox, Switch Pro и обычные геймпады — по Bluetooth или проводу, в Chrome, Edge, Safari и Firefox.
Модель определяется сама (раскладка правится даже там, где браузер её не знает), геймпад можно подключить в любой момент.

| Кнопка | Действие |
|---|---|
| Левый стик / правый стик | бег / камера |
| ✕ (A) | прыжок, выбрать |
| ○ (B) | рывок, назад |
| □ (X) | удар |
| △ (Y), L2 | рогатка (L2 держать — целиться) |
| L1 / R1 | мёд / поднять друга, подарить |
| R2 | рывок |
| L3 / R3 | метка / сменить оружие (держать — эмоция) |
| Share (Create) | таблица очков |
| Options | пауза (там «Настройки» и «Управление») |
| Тачпад (держать) | говорить |
| Крестовина | меню; в одиночной игре — бег, с друзьями — быстрые фразы |

Кнопки геймпада тоже переназначаются (кроме ✕/○ в меню, Options и крестовины). Отдаление камеры на геймпаде по умолчанию
не назначено — назначь кнопку в «Управлении» или поставь «Дальность камеры» в «Изображении».

## Игра с друзьями (до 6 человек)

Меню → «Играть с друзьями»: создай комнату и скинь друзьям 5-буквенный код (или ссылку `…/?room=КОД`), войди по коду
или нажми «Быстрая игра» — попадёшь к случайным игрокам. В комнате — чат, голос, «Я готов», хост выбирает главу и
сложность. Всё проходится и в одиночку, но вместе сложнее и веселее:

- упавшего друга можно поднять, пока он не истёк (держи R рядом); если упали все — команда начинает со свечки;
- подсадка: запрыгни другу на голову и прыгни ещё раз — суперпрыжок; плиты на двоих открывают тайники;
- ударь лапшу, щупальце или кулак Короля, который держит друга, — освободишь его; «Командный хлопок» — двое бьют
  по двум ладоням Короля почти одновременно, и он оглушён;
- враги крепче, Король злее; в погоне он охотится на отстающего, а совсем отставшего швыряет к команде;
- у каждого свои крошки и находки; таблица очков, комбо-серии, корона лидера (Король ненавидит лидера), MVP и
  шуточные звания в итогах главы;
- PvP «Крошечная лихорадка» в комнате — 2 минуты собирать крошки и выбивать их из соперников.

Связь: комнаты, поиск и чат — через Supabase, игра и голос — напрямую между игроками (WebRTC). Если у игроков очень
строгие сети, пригодится свой TURN-сервер: задай `VITE_TURN_URL`, `VITE_TURN_USER`, `VITE_TURN_PASS` при сборке.
В режиме разработки (`npm run dev`) игра без звука; добавь `?music=1`, чтобы слышать.

В погоне (глава 4) Тоша бежит сам: A / D — уворачиваться, W — быстрее, S — притормозить, Пробел — прыжок, Shift — рывок.
Король бежит чуть быстрее обычного бега — держи W и не спотыкайся. Над экраном шкала «Король позади»: догонит — минус
два сердечка. Упал в суп — тебя вернёт чуть назад, а Король отступит.

## Враги

Арбузята видят конусом впереди (до ~15 м, через стены и ящики — нет) и слышат шаги, приземления, удары и горох,
ударившийся о стену. Над головой: «?» наполняется, пока стражник присматривается; «!» — заметил и поднял тревогу
(соседи бегут на помощь); оранжевый «?» — ищет там, где видел тебя последний раз. Удар по стражнику, который тебя
не заметил, — двойной. Нападают не больше двух за раз, остальные кружат рядом.

- Стражник с копьём — выпад, иногда два подряд; отпрыгивает от твоих ударов.
- Щитоносец — крышка спереди отбивает удары и горох. Обойди, ударь вертушкой сверху или пробей щит вилкой.
- Бомбардир — держит дистанцию и кидает вишнёвые бомбы (красный круг на полу). Бомбу можно отбить мечом обратно
  или лопнуть горохом — взрыв ранит и арбузов.
- Таран — роет землю (полоса на полу показывает разбег) и несётся по прямой. Врежется в стену — оглушён, урон ×2.
- Плевун, фрикаделька, желе (большое делится на два), летающие книги (кружат и пикируют по очереди).
- Макаронный монстр — броня: обычный удар снимает 1. Бей, когда он устал после удара щупальцами, или оглуши
  горошиной в глаз. На половине здоровья злится: двойные удары, плевки фрикадельками, детки-фрикадельки.

## Крошки, орешки и лавка

- Крошки — валюта: лежат на уровнях, падают с врагов, спрятаны в ящиках и банках (разбей). Падение (смерть) стоит
  15% крошек в кармане. Убитый враг после возрождения у свечки появляется снова, но крошек больше не даёт.
- Золотые орешки — по 3 спрятано в Кладовой, Пиршественном зале и Библиотеке, 2 — в Погоне. Медведь меняет их
  на особые улучшения.
- После главы — «Итоги»: крошки, враги, орешки, пропущенные удары, падения, время. За хорошую игру — бонусные
  крошки и медаль (бронза / серебро / золото), лучшая медаль видна в списке глав.
- Лавка медведя: сердце-вишня, точильный камень, мёд, магнит для крошек, мешочек гороха, крышка-щит (поглощает
  удар, заряжается у свечек), медовые соты, ветряной плащ; за орешки — ореховое сердце и ореховая рогатка.
  Всё не купить — выбирай.
- Артефакты достаются в бою: Перо Прыгуна, Вилку и Плащ-Рывок охраняют засады.

У босса (глава 5) каждый удар заранее подсвечен на полу: светящийся круг — сюда хлопнет ладонь, полоса — сейчас
проедет рука (перепрыгни или уйди с полосы). Застрявшую ладонь можно бить (и по пальцам тоже), котлету — отбить мечом
Королю в лицо: он рухнет носом в пол, и тогда бей по носу. С каждой фазой он быстрее и злее: катит фрикадельки
по дорожкам, хватает кулаком (жми прыжок/удар, чтобы вырваться, иначе съест), метёт двумя руками крест-накрест,
вызывает разную стражу (щитоносцы, бомбардиры, тараны, желе, книги). Если долго стоишь на месте — накажет,
если тебя сильно побили — даст передохнуть и уронит сердечко.

## Что внутри

- 5 глав: Кладовая (полки-этажи) → Пиршественный зал (Король ест на троне во главе стола, слуги-арбузы носят ему блюда,
  а его рука хватает закуски — не попадись под ладонь; хлебная стена, макаронный монстр, засада на блюде)
  → Библиотека (подъём по спирали из книг, выход — волшебная книга) → Погоня (Король проламывает стену; качающаяся лапша,
  стражники в ряд, макаронный монстр, рвы с супом) → Король Громадин (босс в 3 фазы).
- 3D-заставки на движке, диалоги с портретами, берлога медведя Вторника — магазин улучшений.
- Всё — модели, текстуры, музыка, звук — генерируется кодом, без внешних файлов.
- Мультяшный рендер: toon-шейдинг + контуры пост-эффектом (можно выключить в настройках).

## Структура

- `src/three` — 3D: рендер, камера, физика, частицы, модели (`models/`), реквизит и комнаты (`world/`), игра (`game/`)
- `src/engine` — ввод, звук и музыка (синтез), сохранения
- `src/ui` — диалоги, HUD, меню; `src/scenes`, `src/art`, `src/game` — 2D-версия и общие части
